# Computational Physics Repository

This repository contains a collection of codes and scripts for **computational methods in physics**, ranging from quantum many-body simulations to statistical data analysis. It serves as a resource for learning, testing, and applying computational techniques to physical systems.  

The examples and exercises are inspired by coursework from **LMU Munich** and **TUM**, covering a variety of topics in computational physics. They are intended as a reference for implementing physics simulations and data analysis techniques.

## Features

- **Quantum Many-Body Simulations**  
  Scripts for simulating quantum systems, including lattice models, time evolution, and exact diagonalization, neural quantum states.

- **Bose-Hubbard Time-of-Flight Calculations**  
  Code for calculating time-of-flight distributions for the Bose-Hubbard model experiments with neutral atoms.  

- **Statistical Analysis & Data Processing**  
  Tools for data fitting, regression, and statistical analysis, including curve fitting and visualization.  

- **General Computational Methods**  
  Examples of numerical integration, matrix operations, and other computational techniques commonly used in physics.
